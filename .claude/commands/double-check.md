# /double-check

사용자가 직전에 준 지시를 받아 5요소로 분해하고 사용자 확인을 요청한다.

## 인자

`$ARGUMENTS` — 더블체크할 지시 텍스트 (또는 직전 사용자 메시지)

## 실행

1. `bash .claude/hooks/lib/double-check-incr.sh` (KPI 카운터 +1)
2. LLM이 5요소 답변 생성:
   - 목표 / 범위 / 수용 기준 / 제약 / 위험
3. 마지막에 "이대로 맞나요? 아니면 X/Y/Z 중 수정?" 명시
