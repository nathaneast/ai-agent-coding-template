# Skill: double-check

`/double-check` 슬래시 커맨드. 사용자 지시를 받은 직후 호출하여 이해를 사용자에게 더블체크.

## 흐름

1. 사용자 지시 텍스트 분석
2. 다음 5개 요소를 명시적으로 답변:
   - **목표 (Goal)**: 무엇을 달성하려고 하는가?
   - **범위 (Scope)**: 무엇이 포함/제외되는가?
   - **수용 기준 (Acceptance)**: 무엇이 "완료"인가?
   - **제약 (Constraints)**: 시간/품질/도구 제약?
   - **위험/불확실성 (Risks)**: 어디가 모호한가?
3. 사용자 확인 또는 정정 요청 ("이대로 맞나요? 아니면 어디 수정?")

## 사용 시점

- 새로운 작업 시작 직전 (특히 모호하거나 다중 해석 가능 시)
- "다 해줘", "알아서 진행" 같은 포괄적 지시 받았을 때
- 사용자 부재 무인 빌드 시작 전 마지막 확인 단계

## KPI

각 `/double-check` 호출 시 `.omc/learnings/_metrics.json`의 `double_check_invoked` 카운터 +1.
