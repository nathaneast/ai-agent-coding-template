## 기본 폴더 운영 규칙

- `policy`
  - 프로젝트를 진행을 위한 엄격한 기본 규칙

- `spec`
  - 서비스 기획, 디자인, 기술 관련 기준 문서를 저장한다.
  - 구현 전 의사결정과 정책은 `spec` 문서를 기준으로 확정한다.

- `task`
  - `spec` 문서를 참고해 `todo.md`를 작성하고 작업 목록을 관리한다.
  - 작업이 완료될 때마다 `todo.md` 체크 상태를 갱신한다.
  
- `prompt`
  - 사용자가 작성한 프롬프트를 아카이빙할 때 사용하는 폴더다.
  - 과거 프롬프트 이력 보존 목적 외의 정책 문서는 저장하지 않는다.
  
- `feedback`
  - 프로젝트 진행 중 아쉬운 점, 개선 필요 사항, 회고 메모를 아카이빙하는 폴더다.
  - 기능/운영/프로세스 개선 아이템을 누적 기록하고 추후 개선 우선순위 논의에 활용한다.
