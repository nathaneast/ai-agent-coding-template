# User Global Memory — Cross-Project

횡단(cross-project) 사용자 글로벌 메모리. 모든 프로젝트에 공통 적용되는 작업성향·금기·골을 정의.

- [user.md](./user.md) — 작업성향 (코드 스타일/PR 크기/리뷰 깊이 등)
- [comfort.md](./comfort.md) — 쾌적한 작업 흐름·페이스·환경
- [goals.md](./goals.md) — 작업관점·장기 골 (도메인·기술)
- [dont.md](./dont.md) — 금기 (이전 사고에서 배운 횡단 don'ts)
- [CHANGELOG.md](./CHANGELOG.md) — 글로벌 메모 정정 로그 (append-only)

_본 디렉토리는 모든 프로젝트에 SessionStart로 inject됩니다._

_사적 정보(이름·금액·NDA·키) 절대 금지. yunjadong-team 조직 레포 공개 범위._
