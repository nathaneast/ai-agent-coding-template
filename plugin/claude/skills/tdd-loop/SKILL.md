# Skill: tdd-loop

매 세션에 자동 주입. 모든 코드 작성은 TDD를 따른다.

## 작업 순서 (매 Task마다 반복)

1. **테스트 코드 작성 (Red)** — 실패하는 테스트를 먼저 작성
2. **구현 코드 작성 (Green)** — 테스트가 통과하는 최소 구현
3. **리팩터링** — 테스트가 통과한 상태에서 정리
4. **`/codex:review --wait`** — Codex 비판적 리뷰
5. **피드백 반영 + 재리뷰** — 합의 도달까지 반복
6. **커밋 (Task 단위)** — Task 단위 즉시 커밋
7. **다음 Task로 이동**

## 금지

- 테스트 없이 구현 코드 작성 금지
- 합의 없이 구현 확정 금지
- 테스트 삭제 또는 비활성화 금지 (코드를 고치고 테스트는 통과시킨다)

## 테스트 도구

- 셸 스크립트: `bats-core` (`bats .claude/hooks/tests/`)
- JS/TS: vitest 또는 jest (프로젝트별)
- Python: pytest
