# Skill: user-helper

매 세션 자동 주입. **사용자의 비효율 신호를 Claude가 선제 감지**하여 에이전트/스킬 생성을 1줄로 제안한다. 트리거 키워드 없음 — Claude가 대화 흐름을 보고 자율 판단.

## 목적

사용자가 같은 프롬프트를 반복하거나, 매번 길게 장황하게 컨텍스트를 다시 설명하거나, 동일한 좌절을 반복할 때 → Claude가 멈춰서 **"이 패턴, 에이전트/스킬로 자동화할까요?"** 한 줄 제안.

## 감지 신호 (둘 이상이면 제안 발화)

1. **반복 프롬프트**: 같은 세션 내 유사한 요청 2회 이상 (의미 유사도, 단어 일치 아님)
2. **장황 설명**: 사용자 메시지 5문장 이상이면서, 직전 1~2 메시지에서 이미 같은 컨텍스트를 설명한 경우
3. **좌절 신호**: "또 안됨", "왜 자꾸", "계속 이래", "이거 매번", "짜증", "비효율" 류 표현
4. **컨텍스트 재투입**: 매번 같은 파일/디렉토리/규칙을 다시 안내해야 진행되는 경우
5. **수동 반복 작업**: 사용자가 동일한 손작업(파일 열기, 같은 명령어 입력 등)을 여러 번 요청

## 제안 발화 (단 1줄, 끼어들지 않음)

작업 사이클이 한 단위 끝났을 때(= 직전 답변 완료 직후) 다음 형식:

> 🤖 [감지한 패턴 1문장]. [제안 이름] 스킬/에이전트를 만들어 자동화할까요? (yes / 아니오 / 나중에)

**예시**:
- "매번 `.env` 경로 알려주시는데, 프로젝트 진입 시 자동 주입하는 `env-context` 스킬 만들까요?"
- "테스트 실패 → 같은 디버그 명령어 3번째인데, 자동 재실행 스킬 `auto-retest`로 묶을까요?"
- "이 폴더 구조 설명 3번째예요. AGENTS.md 자동 갱신 훅 만들까요?"

## 동작

1. 신호 감지 → 작업 응답 끝에 1줄 제안만 추가 (작업 중 끼어들기 금지)
2. 사용자 `yes`/`해줘` → 즉시 sketch:
   - 위치: `plugin/claude/skills/<제안이름>/SKILL.md`
   - 또는: `plugin/claude/agents/<제안이름>.md`
   - 작성 후 "초안 만들었으니 다음 발생 시 테스트해보고, OK면 `/promote <이름>`으로 템플릿 승격" 안내
3. 사용자 `아니오` → `.omc/proposals-rejected.md`에 1줄 적재 (재제안 7일 억제):
   ```
   - [<ISO8601>] <패턴 요약> :: rejected
   ```
4. 사용자 `나중에` → `.omc/proposals-pending.md`에 적재, 다음 세션에 1회 재제안

## 발화 빈도 제한

- 세션당 최대 **2회** 제안 (스팸 방지)
- 같은 패턴 24시간 내 재제안 금지
- 사용자가 작업에 집중 중일 때(연속 도구 호출 중)는 제안 보류 → 사이클 끝나면 발화

## 승격 흐름 (사용자가 테스트 후 만족)

1. Claude가 만든 초안 스킬을 사용자가 실사용
2. OK → `/promote <skill-name>` 또는 자연어 "이거 템플릿에 넣어"
3. Claude는 `templates/` 또는 영구 위치로 이동, README 등록, commit

## 안전 규칙

- 작업 도중 끼어들지 말 것 (도구 호출 시퀀스 한 단위 끝난 뒤만)
- 1줄 제안 — 사용자가 yes 하기 전엔 sketch 작성 금지
- 동일 패턴 중복 제안 금지 (rejected/pending 파일 먼저 확인)
- 시크릿 의심 패턴 포함된 자동화 제안 금지 (`.env`, 토큰 류 자동 처리 제안 X)

## 로그

- 제안 발화: `.omc/proposals-log.md`에 누적 (감지 → 제안 → 사용자 응답)
- 매주 1회 사용자에게 "이번 주 제안 통계 볼래요?" 자연어 옵션 (자동 보고는 금지)
